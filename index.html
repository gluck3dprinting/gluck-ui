SECTION 00

내 시스템에 적용하기

디자인 파일을 복사하거나 색 코드를 옮겨 적을 필요가 없습니다. 아래 CSS 주소 한 줄을 내 시스템에 연결하면 끝이고, 이후 색이나 버튼 규격이 바뀌어도 모든 시스템에 자동으로 반영됩니다. 개발 지식이 없어도 3단계면 됩니다.

STEP 1 내 시스템의 공통 <head>에 이 한 줄을 붙여 넣기

모든 페이지가 함께 쓰는 HTML 파일(예: index.html, 레이아웃·템플릿 파일)의 <head> 안, 기존 CSS보다 위쪽에 넣습니다. 오른쪽 위 복사 버튼을 누르면 그대로 복사됩니다.

<link rel="stylesheet" href="https://gluck3dprinting.github.io/gluck-ui/dist/gluck.css">
내 시스템이…어디에 넣나요
순수 HTML 페이지index.html 등 각 파일의 <head> (공통 헤더 파일이 있으면 거기 한 번만)
React · Next.jsapp/layout.tsx의 <head> 또는 pages/_document.tsx
Vue · Nuxtindex.html 또는 nuxt.config의 app.head.link
워드프레스 · 웹플로 · 노코드 툴설정의 "헤더(head) 코드 삽입" 영역에 붙여 넣기
관리자 툴 (Madmin · Hermes OS)공통 레이아웃 <head> + 아래 "관리자 툴이라면 한 줄 더" 참고

STEP 2 화면 요소에 GLUCK 클래스 이름 붙이기

버튼·입력창·배지 같은 요소에 아래처럼 클래스 이름만 붙이면 이 페이지와 똑같은 모양이 됩니다. 어떤 클래스가 있는지는 각 컴포넌트 섹션(08~16)에 있고, 그 이름이 곧 실제 사용하는 이름입니다.

<button class="gluck-btn gluck-btn--primary">바로 견적 요청</button>
<input class="gluck-input" placeholder="회사명">
<span class="gluck-badge gluck-badge--success">Deal 성사</span>

STEP 3 적용됐는지 확인하기

이렇게 보이면 성공

  • 버튼이 GLUCK 블루(#0059FF), 글자가 SUIT 서체
  • 입력창 테두리가 회색이고 클릭하면 파란 테두리
  • 브라우저 F12 → Network 탭에 gluck.css 가 200

안 될 때 확인할 것

  • 주소 오타 — 위 복사 버튼으로 다시 붙여 넣기
  • <head> 밖(본문)에 넣음
  • 내 CSS가 같은 요소를 뒤에서 덮어씀 — 그 요소의 내 스타일을 지우거나 GLUCK 링크를 더 아래로

드롭다운·모달·토스트를 쓴다면 (선택)

프레임워크 없이 만드는 페이지라면 아래 한 줄을 추가하면 드롭다운(하나만 열림·ESC), 툴팁 ESC, 헤더/사이드바 드로어, data-modal 모달, gluckToast()가 바로 동작합니다. React·Vue 등은 같은 규칙을 컴포넌트 안에서 구현해도 됩니다.

<script src="https://gluck3dprinting.github.io/gluck-ui/dist/gluck.js" defer></script>

관리자 툴이라면 한 줄 더

Madmin·Hermes OS처럼 하루 종일 데이터를 다루는 화면은 <html> 태그에 data-theme="admin"을 붙입니다. 회색 앱 배경, 채도 낮은 블루, 밀도 높은 테이블로 바뀝니다. 홈페이지·랜딩은 생략(기본 라이트), 다크를 지원하려면 data-theme="dark".

<html lang="ko" data-theme="admin">

Claude 같은 AI 도구로 개발 중이라면

사람용 페이지 대신 AI용 참조 파일 주소를 알려주면 클래스·토큰 이름을 정확히 씁니다. 프로젝트의 CLAUDE.md(또는 AI 도구의 지침 파일)에 아래 문단을 붙여 넣으세요. 이후 "GLUCK 디자인 시스템으로 만들어 줘"라고만 해도 규칙대로 작성합니다.

## 디자인 시스템 (필수)
- GLUCK 공용 디자인 시스템을 따른다. 작업 전에 https://gluck3dprinting.github.io/gluck-ui/llms.txt 를 읽고 규칙·클래스·토큰 이름을 그대로 사용할 것.
- <head>에 <link rel="stylesheet" href="https://gluck3dprinting.github.io/gluck-ui/dist/gluck.css"> 를 넣는다.
- 색·간격·라디우스는 var(--color-*), var(--space-*), var(--radius-*) 시맨틱 토큰만. HEX·px 리터럴 금지.
- 버튼/입력/배지/카드/테이블은 .gluck-* 클래스를 사용하고 재구현하지 않는다.
- 관리자 툴이면 <html data-theme="admin">.

참조 파일 직접 보기: llms.txt — 규칙 10개, 모든 컴포넌트 클래스, 토큰 이름, 아이콘 id가 한 파일에 있습니다.

SECTION 01

로고 · 아이덴티티

시그니처는 워드마크 단독형입니다. 심볼 결합형은 존재하지 않으며 만들지 않습니다. 텍스트로 "GLUCK"을 조판해 로고를 대신하는 것도 금지 — 항상 SVG 원본(#lg-wordmark)을 사용합니다.

CLEAR SPACE

사방 1G(첫 글자 G의 높이) 확보. 그 안에 텍스트·다른 로고·사진 요소 금지.

SMALL SIZE · G SYMBOL

파비콘·앱 아이콘·아바타 등 소면적은 G 심볼. 최소 사용 크기는 브랜드 규정 미게시 TBD. 파비콘은 원본 파일(assets/logo/GLUCK_Favicon.*)만 사용, 재제작 금지.

DO

  • 블랙 / 화이트 / 블루(#0059FF) 3가지 컬러웨이만
  • 단색 적용: 사진·컬러 배경 위는 화이트 또는 블랙 단색

DON'T

  • 텍스트 "GLUCK"(SUIT 800) + 파란 점 등 로고 흉내

  • 비율 변경 · 그라데이션 · 외곽선 · 그림자 · 회전

컬러 토큰

3계층입니다. Primitive(원시 값)는 팔레트일 뿐이고, 컴포넌트와 제품은 Semantic(역할 이름)만 씁니다. 테마(다크·관리자)는 시맨틱 값만 갈아끼우므로 컴포넌트는 한 벌입니다. 아래 값은 전부 이 페이지에 실제 로드된 CSS 변수에서 읽어 표시합니다. 토큰 이름·계층 규칙은 개발자 문서에 있습니다.
